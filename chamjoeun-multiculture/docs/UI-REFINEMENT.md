# 연혁·업무협약 이미지 개편

2026-11-02 사용자 요청 반영. Vercel 프로덕션 주소에 배포 완료.

- 연혁의 14개 이력을 3개 시기로 묶고, 한 번에 한 연도의 주요 내용만 표시합니다.
- 시기·연도 선택, 이전/다음 이동, 전체 연혁 펼치기·접기를 제공합니다. 원래 이력 문구는 유지합니다.
- 연도 전환 애니메이션과 움직임 최소화 설정을 지원합니다. 키보드 버튼 조작·상태 안내·모바일 가로 넘침을 확인했습니다.
- 페이지 초기화 전 클릭이 유실되지 않도록 상호작용 버튼은 클라이언트 준비 후 활성화합니다.
- 휴대폰 상담 버튼을 원형 아이콘으로 줄이고 연혁 이동 버튼은 왼쪽에 배치합니다.
- 공개 협약 20건에 JPEG 이미지 30장을 등록했습니다. PDF는 페이지별 이미지로 변환하고, 행사 사진이 있는 글은 사진을 대표 이미지로 표시합니다.
- DB에 등록한 공개 이미지 30개 모두 외부 URL의 상태·형식·해시 일치를 확인했습니다. 중복 스캔 한 벌과 비공개 초안은 공개 이미지 등록에서 제외합니다.
- 외부 PostgreSQL 초기 연결 여유 시간을 10초로 조정하고 유휴 연결 오류 처리기를 추가했습니다.

검증: 타입 검사, 단위 테스트 15개, Vercel Webpack 빌드 통과. 별도 테스트 브라우저로 실제 배포 주소의 연도·시기 선택, 14개 전체 이력, 모바일 키보드 펼치기·접기, 움직임 최소화, 실제 게시물 이미지 표시를 확인했습니다. 데스크톱 연혁 기본 영역은 약 742px입니다.
