# 개발 현황과 이어갈 작업

기준: 2026-11-02. 코드가 있는 기능, 이번에 검증한 기능, 외부 연동이 필요한 기능을 구분한다.

## DB 상태

- 현재 앱 연결 대상: 외부 검토 PostgreSQL 18.6. 사용자 요청에 따라 `.env.local`을 외부 DB로 전환하고 개발 서버 재시작. 인증서 검증(sslmode=verify-full) 적용, 마이그레이션 8개 적용.
- 로컬: 이전 PC 경로의 데이터 디렉터리가 없어 연결 거절 상태였음. 2026-10-26 백업을 별도 로컬 DB로 복구하고 최신 마이그레이션 적용.
- 이전 로컬 연결 설정은 `.local/.env.local-db-before-external`에 보관. 로컬 런타임은 `.local/runtime.json` 참고. 연결 자격증명을 커밋하거나 공개하지 않음.
- `npm run db:check`로 연결·버전·누락 마이그레이션 확인 가능. 결과에 접속 비밀번호를 출력하지 않음.
- 저장된 데이터 경로가 사라졌을 때 `db:local`이 조용히 빈 DB를 만드는 동작을 차단. 새 환경을 명시적으로 초기화한 후 백업 복구 필요.
- 백업 도구는 고정 DB명 대신 `.env.local`의 실제 로컬 DB 연결 대상을 사용.

## 구현 코드가 있는 영역

- Next.js 16 / React 19 / PostgreSQL, 기관·사업·정착지원 안내와 KIIP 외부 연결.
- 회원가입·이메일 인증·로그인·로그아웃·서버 세션·관리자 권한, 비밀번호 복구·인증 재발송·프로필 수정·탈퇴.
- 구글·네이버·카카오 OAuth와 계정 연결. 제공자 계정 키·실제 콜백 검수는 별도 필요.
- 관리자 과정·차시 관리, 무료 신청, 유료 주문·토스 승인/웹훅·전체취소 코드.
- 내 강의실, 차시별 시청 구간·일별 학습시간·이어보기·자동/수동 수료.
- 관리자 영상 업로드, 비공개 R2 저장소, FFmpeg HLS 변환 작업자, 서명 검증 Worker.
- 수료증·자격증 발급과 PDF 다운로드, 과정 안내 PDF. 기관 승인 양식과 실데이터 검수는 미완료.
- 기관소식·검색·편집·숨김·첨부, 기관 기본정보·배너·팝업 관리.

## 이번 보완

1. 로그인 상태에서 문의를 접수한 계정의 ID를 저장. 이메일 일치만으로 과거·비회원 문의를 계정에 귀속하지 않음.
2. `/mypage/inquiries`에서 본인 문의·답변만 조회하고 10건 단위로 이동. 회원 문의 답변은 화면에서 확인 가능. 비회원 문의는 별도 이메일 안내 필요.
3. 학습 일시정지·종료·페이지 이탈·백그라운드 전환 시 진도 저장. 저장 요청을 순서대로 처리하고 이탈 요청에 keepalive 적용. 강제 프로세스 종료·오프라인 저장 성공을 보장하지는 않음.
4. 학습 시작·진도 저장 시 서버가 수강권과 세션을 다시 검증한 뒤 영상 토큰 발급. HLS 요청에 갱신된 토큰 사용. 브라우저 기본 HLS는 만료 전 재연결하며 위치를 복원. 실제 R2·Safari 장시간 재생 검수 필요.
5. 관리자 기관정보를 헤더·푸터·메인·문의·기관소개/지도·로그인·정착지원·약관·개인정보·빠른 전화 링크에 연결. React cache는 요청 범위에서 중복 조회만 줄임.

## 검증 범위

- 타입 검사, 단위 테스트와 실제 PostgreSQL·HTTP 통합 테스트를 구분.
- 통합 테스트: 전체 마이그레이션 적용, 중복 수강 방지·롤백, 비로그인 차단, 본인 문의/답변·페이지 이동·비회원 문의 비공개, 진도 저장·이어보기·자동 수료·기존 세션 무효화·수강 취소 후 차단, 기관정보 공개 화면 반영.
- 테스트에서 만드는 회원·문의·교육 데이터는 테스트 종료 시 삭제. 기관정보 테스트는 원래 값으로 복원.
- 실제 결제, 메일 발송, 소셜 제공자 인증, 영상 업로드/변환/모바일 재생·동시접속은 외부 서비스 설정 후 별도 검증.

## 이번 실행 결과

- 타입 검사 통과, 단위 테스트 12개 통과.
- 로컬 PostgreSQL·개발 서버 HTTP 통합 테스트 5개 통과.
- Webpack 배포 빌드 통과: npm run build -- --webpack. 기본 Turbopack 빌드는 장시간 컴파일 단계에 머물러 중단.
- 새 백업을 임시 DB에 복원해 32개 테이블의 행 수 일치 확인. 검증용 임시 DB는 제거.
- 운영 모드 서버를 추가 실행하는 명령은 자동 승인 검토에서 정책 차단됨. 따라서 운영 모드 HTTP 재검증은 수행하지 못함.

## 외부 DB·업무협약 후속 반영

- 사용자 지정 이메일로 외부 DB 관리자 생성. 실제 비밀번호 로그인과 관리자 원본 목록 HTTP 접근 검증.
- 협약 21건 등록: 공개 요약 20건, 확인 대기 비공개 초안 1건. 원본·행사 사진 31개(69,395,716 bytes)는 관리자 전용 DB 보관.
- 날짜의 일이 공란인 자료는 월 단위로 기록. 같은 협약의 스캔본·여러 페이지·관련 행사 사진은 묶어서 보관.
- 원본 해시 검증, 트랜잭션 등록, 반복 실행 중복 방지와 기존 수동 편집 보존. 데이터 목록과 실행법은 docs/MOU-IMPORT.md 참고.
- 현재 기본 연결이 외부 DB이므로 test:integration의 로컬 전용 보호 조건이 작동. 전체 변이 테스트는 별도 로컬 DB·서버에서만 실행.
- 타입 검사·단위 테스트 15개·Webpack 배포 빌드 통과. 외부 배포 사이트에서도 새 관리자 계정의 실제 로그인과 관리자 접근 성공. 외부 DB 대상 검증은 원본 비공개·관리자 다운로드·공개 목록·초안 비공개 등 필요한 HTTP 검사로 제한.

## 남은 작업

1. Resend 발송 도메인·키, 토스 테스트/운영 키·웹훅, 구글·네이버·카카오 앱 키·콜백, R2 버킷·CORS·Worker·변환 서버 설정과 실연동 검수. 로컬에 해당 서비스 키가 없는 상태.
2. 알림톡·문자·Web Push·뉴스레터 발송 작업자·실패/재시도·수신거부·발송 이력 운영 화면. 현재 알림/발송 테이블과 일부 적재 코드만 존재.
3. MOU 확인 대기 1건의 체결 확정 여부 확인. 승인된 수료증/자격증 양식, 5과정·30차시 실제 원고·영상 등록.
4. 재수강·기간 연장·수료 기준 변경·개인정보 보유/파기·환불 정책 확정. 약관·개인정보 문서는 초안 유지.
5. 실영상 50명 동시 시청·장시간/배속/버퍼링·모바일/키보드·백업 복구·비용/오류 알림·배포 검수.
6. 외부 DB의 007·008 마이그레이션과 MOU 데이터 등록은 완료. 새 관리자 원본 화면과 연혁 개편 등 코드 변경은 Vercel 외부 사이트에 배포 반영.

## 작업 원칙

운영 비밀번호·키를 소스에 저장하지 않음. 미설정 외부 연동을 성공으로 표시하지 않음. 계약 외 기능·운영 정책·추가 비용은 별도 구분. 고객이 확인하지 않은 지정번호·실적·협약 내용을 만들지 않음.
