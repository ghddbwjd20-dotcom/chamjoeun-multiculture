# 개발 현황과 이어갈 작업

기준: 2026-10-26 / 최신 UI v4 및 고객 대화 / PostgreSQL 선택 최종 반영.

## 첫 단계 구현

1. 전체를 하나의 Next.js 프로젝트로 구성. pg 연결 풀, SQL 버전 관리·트랜잭션 도입.
2. users·sessions·auth_tokens·rate_limits·courses·lessons·enrollments·lesson_progress·watch_sessions·inquiries·posts·audit_logs·video_jobs·orders·issued_documents 기본 스키마.
3. 공공기관 중심의 흰 헤더와 네이비·블루, 키보드 focus 하위메뉴, 모바일 메뉴.
4. 평생교육·민간자격·지역사회서비스투자·도서납품 4대 사업을 앞세운 메인. 법무부 관련 안내와 LMS를 분리해 연결.
5. KIIP는 Socinet 외부 과정조회. 계약 제외인 과제·퀴즈·다국어·앱은 추가하지 않음.
6. 이메일 인증 후 로그인, 서버 세션, 비밀번호 해시, 권한 검증, 입력 검증, 작업 이력.
7. 자체 무료 교육과정 신청과 중복 방지, 내 강의실, 수강 기간 검사.
8. 시청 구간 합집합·서버 경과시간 검사, 동시 세션 갱신 제한과 자동 수료 기록. 과정 진도는 차시 시간 가중 방식의 초안.
9. 관리자 과정/차시 관리·회원/수강 조회·사유 있는 수동 수료·문의 답변 기록·뉴스 게시.
10. HLS 플레이어·만료 서명 URL·비공개 R2 Worker 소스. 배포/실영상 검증은 미완료.

## 현재 제한

- 학습 저장은 약 10초 간격. 마지막 저장 후 탭을 강제 종료하면 최근 구간 일부를 잃을 수 있음. 종료 직전 저장과 장시간·배속·버퍼링·동시기기 테스트를 보강해야 함.
- 자동 수료 기준 변경은 다음 학습 기록 갱신부터 적용. 기존 수료 소급 취소는 하지 않음. 최종 정책 승인 필요.
- 수강기간 만료/취소 후 재신청은 자동 갱신하지 않음. 재수강 정책을 정한 뒤 처리.
- 영상 토큰은 최대 15분. 장시간 재생에 대한 토큰 자동 갱신과 폐기 정책은 다음 작업.
- 시청 이벤트는 신뢰할 수 없는 브라우저 입력. 시간·구간 검증을 적용했지만 부정 시청 완전 방지를 보장하지 않음.
- 무료 신청은 게시된 자체 과정에만 가능. 유료과정은 결제 연동 전 신청 차단.
- 문의 자동 이메일 응답, 게시글 편집·숨김·첨부, 페이지네이션, 회원별 시청시간 관리 화면은 미완료.
- MOU는 제공 파일 목록만 확인한 상태. 기관/날짜/중복/공개범위 전수 대조 후 실콘텐츠 게시.
- 약관·개인정보처리방침은 개발 초안. 확인 전 실사용자 모집 금지.
- rate limit 정리·세션 정리·로그 보존 정책·운영 알림, 소셜계정 연결 정책과 계정 보안 흐름 보강 필요.
- 외부 API 비정상 응답에 대한 인증메일 재발송·복구 처리 보강 필요.

## 다음 개발 우선순위

### 1. 영상 실제 처리

R2 계정·비공개 버킷·CORS·Worker → 관리자 멀티파트 직접 업로드(10GB) → 큐와 FFmpeg 1080/720/480 HLS·썸네일 → 처리/실패·재시도 → 차시 연결 → 토큰 갱신·접근권한·다기기 학습 검수.

### 2. 회원과 운영 콘텐츠

계정 찾기·재설정·이메일 재발송, 정보 수정·탈퇴, 네이버/카카오/구글 OAuth와 중복 처리. 공지 편집·첨부, 회사정보·배너·팝업, MOU 게시.

### 3. 결제·발급·알림

토스 테스트 주문/승인·금액 검증·웹훅·멱등성·전체취소/환불 상태·수강권. 승인 양식 수료증1종·자격증1종 PDF와 고유번호·발급내역. 솔라피·알림톡·Web Push·뉴스레터와 동의·수신거부·발송 이력.

### 4. 오픈 검수

초기 5과정·총30차시 등록. 실영상 50명 동시 시청 기준 부하, 모바일·키보드·대체텍스트·낭독구조, 백업 복구, 비용 사용량 시뮬레이션. 고객 검수·잔금·배포·소스/DB자료/매뉴얼·온라인 교육1회.

## 작업 원칙

운영 계정 비밀번호·키를 소스에 저장하지 않음. 고정 데모 계정 자동 로그인 없음. 고객이 확인하지 않은 지정번호·기관 성과·원고를 사실처럼 만들지 않음. 외부 리소스 비용은 실견적 후 실행. 추가 기능과 계약 외 사항은 작업량을 구분해 기록.
