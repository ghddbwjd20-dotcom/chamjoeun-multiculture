# 업무협약 DB 등록과 원본 보관

기준: 2026-11-02. 현재 개발 사이트도 외부 PostgreSQL에 연결되어 있습니다.

## 등록 결과

- 협약 21건: 요약 공개 20건, 확인 대기 비공개 초안 1건.
- 원본·행사 사진 31개: 69,395,716 bytes(약 66.2 MiB). 로고 2개는 협약 자료에서 제외.
- 원문 날짜, 당사자 명칭, 주요 협력 범위를 대조해 `data/mou-catalog.json`에 기록.
- 날짜의 일이 비어 있는 자료는 월까지만 기록. 원문에 없는 일자나 현재 협약 유효 여부를 추정하지 않음.
- 같은 날짜의 한국열린사이버대학교 스캔본은 1개 협약으로 통합. 김해대학교의 가족회사·산학협력 문서는 1개 게시물로 묶음. 여성일자리 협약서의 두 면과 협약별 행사 사진도 각각 해당 협약에 귀속.
- 고려사이버대학교 자료는 원문 제목의 '(안)' 표기 때문에 체결 확정 여부 확인 전 비공개 초안으로 등록.

## 화면

- 공개 요약: `/news?category=업무협약`. 협약일과 등록일은 별개이며 상세 화면에 구분 표시.
- 관리자 원본: `/admin/agreements`. 원본·사진 다운로드와 게시물 편집 연결 제공.
- 원본 API: `/api/admin/agreements/[id]`. 관리자 인증 필수. 비로그인·일반회원은 404. 공개 게시물의 첨부파일 경로로 연결하지 않음.
- 원본은 외부 DB의 `agreement_documents.data`에 저장하고 SHA-256·원본 파일명·크기를 함께 보관. 공개 메타데이터는 `agreements`, 요약은 기존 `posts` 사용.
- 현재 로컬 주소는 외부 DB를 사용하지만 로컬 웹서버 주소 자체를 다른 사람에게 공유할 수는 없음. 외부 방문자는 기존 배포 사이트 주소로 접속.
- 새 관리자 원본 화면 등 이번 코드 변경은 별도 사이트 배포 후 외부 사이트에서도 사용 가능. 기존 배포의 업무협약 게시판은 같은 DB의 공개 요약을 읽음.

## 재실행

```powershell
npm run db:check
npm run mou:import
npm run mou:import -- --apply
```

첫 번째 import 명령은 파일 존재·크기·형식·SHA-256 검증만 하며 DB에 쓰지 않습니다. `--apply`가 있어야 현재 DATABASE_URL에 등록합니다. 원본 폴더 기본값은 `../MOU`, 별도 위치는 MOU_SOURCE_DIR 환경변수로 지정합니다.

- 등록은 하나의 트랜잭션으로 처리. 중간 실패 시 롤백.
- source_key로 게시물 중복 생성을 방지하고 기존 게시물 수동 편집을 덮어쓰지 않음.
- 동일 경로의 원본 해시가 바뀌면 등록 중단. 문서 변경은 원본을 다시 검수한 후 명시적으로 처리.
- 원본 경로의 상위 이동·드라이브 경로·심볼릭 링크의 폴더 외부 접근을 차단.
- DB 인증 정보와 관리자 비밀번호는 Git에 포함하지 않음. 기존 로컬 환경 설정은 `.local/.env.local-db-before-external`에 보관.

## 검증

타입 검사·단위 테스트 15개·Webpack 배포 빌드 통과. 실제 외부 DB에 최초 등록 21건, 재실행 신규 0건을 확인했습니다. 실제 비밀번호 로그인(개발·외부 배포 주소), 관리자 목록, 원본 접근 권한·다운로드 해시, 공개 목록·초안 비공개를 HTTP로 점검했습니다. DB에 보관한 31개 파일 전체의 SHA-256 일치도 확인했습니다. 외부 배포 사이트에서도 공개 20건과 검색 결과를 확인했습니다. 현재 기본 연결이 외부 DB이므로 로컬 전용 전체 통합 테스트를 외부 DB에 실행하지 않습니다.

## 공개 이미지 반영

2026-11-02 사용자 요청으로 공개 협약 20건에 이미지 30장을 연결했습니다. PDF는 페이지별 JPEG로 변환하고 사진은 방향·크기를 웹 표시용으로 정리했습니다. 동일한 한국열린사이버대학교 협약의 중복 스캔은 한 벌만 표시하며, 확인 대기 초안은 계속 비공개입니다. 원본 파일은 관리자 전용 보관을 유지하고 공개용 이미지 사본은 attachments/attachment_files에 저장합니다. 협약식 사진이 있는 글은 사진을 먼저 표시합니다.

이미지 준비는 scripts/prepare-mou-images.py, 등록 검증은 npm run mou:publish-images, 실제 반영은 npm run mou:publish-images -- --apply를 사용합니다. 같은 자료를 반복 실행해도 중복 생성하지 않습니다. 공개 이미지 30개 모두 외부 URL의 응답·JPEG 형식·SHA-256 일치를 확인했습니다.
