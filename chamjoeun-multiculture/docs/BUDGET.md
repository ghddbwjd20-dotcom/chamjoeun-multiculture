# 월 10만 원 이하 인프라 설계안

승인된 목표: **웹서버 + PostgreSQL + 영상 저장·전송·변환 합계 월 100,000원 이내**. 현재 비용을 발생시키는 클라우드 리소스는 생성하지 않았다.

## 선택한 구조

- 한 대의 VM에 Next.js와 PostgreSQL을 직접 운영. DB 라이선스·별도 관리형 DB 사용료 없음.
- 원본/변환본을 비공개 Cloudflare R2 Standard에 저장. R2 외부 전송료 무료. 저장량과 요청 수 과금은 별도.
- HLS 변환은 FFmpeg를 단일 작업으로 처리. 관리형 인코딩 상품 비용을 추가하지 않음.
- 공개 원본 MP4·웹 VM 영상 중계는 하지 않음. Worker에서 토큰 검증 후 R2 영상 제공.
- Redis·쿠버네티스·별도 관리형 DB를 추가하지 않음. 작업 큐는 PostgreSQL 기반으로 설계.

## 내부 지출 한도 배분 (실제 상품 견적 아님)

| 항목 | 월 배분 상한 (부가세·환율 고려한 원화 목표) |
|---|---:|
| VM·디스크·IP 등 웹/DB 실행비 | 44,000원 |
| R2 영상 저장 (원본+HLS 합산 500GB 시나리오) | 13,000원 |
| Worker 요청·인증 (Paid 기본료 수준 가정) | 9,000원 |
| 백업 저장·VM 외부 전송·변환 여유분 | 19,000원 |
| 비용 변동 예비분 | 15,000원 |
| 합계 | 100,000원 |

VM 44,000원은 NCP 특정 사양의 확인된 가격이 아니라 구매 허용 상한이다. 이 금액에 충분한 메모리·디스크·고정 IP·트래픽이 포함되는 상품을 찾지 못하면, 리소스 생성 전에 사양/호스팅 대안을 조정해야 한다. 저사양으로 계약 기능을 임의 삭제하지 않는다. 실제 50명 동시 영상 재생 성능은 별도 검증한다.

R2 Standard 공식 단가: 저장 $0.015/GB-month, 월 10GB 무료, Class A $4.50/백만회, Class B $0.36/백만회. 각각 월 무료 제공량과 반올림 규칙이 있다. 500GB 합산 저장 시 (500-10)×$0.015=$7.35. 환율 1,600원과 세금 10%를 가정하면 약 12,936원이다. 환율/세금은 예산 시나리오이며 실제 청구 기준이 아니다.

**500GB 원본**에 HLS 3화질을 추가하면 합산 500GB를 초과할 수 있다. 계약의 500GB 설계 기준과 원본/결과물의 합산 용량을 구분하고, 원본 보관·삭제 정책을 고객과 정한다. 계약상 업로드 10GB 한도를 낮추지 않고, 프로젝트 전체 저장 여유가 없으면 업로드 전에 안내한다.

영상 변환 자체는 오픈소스로 처리해도 CPU·임시 디스크와 결과물 전송비가 든다. 동시에 한 작업만 수행하고 웹 서비스 여유를 확인해야 한다. VM 외부 전송 단가와 월 신규 영상량을 실제 견적에 포함한다.

Worker 요청 수는 재생 시간과 세그먼트 길이에 비례한다. 예: 50명×하루1시간×30일÷6초 세그먼트 ≈90만 세그먼트 요청/월. 재생목록 조회·관리자 접근·탐색·재시도·추가 시청은 별도. 전체 500GB 저장·초기 합의 규모를 무제한 이용료 보장으로 해석하지 않는다.

## 비용 제어: 구현 전 반드시 구분할 것

- 현재 구현: 외부 유료 서비스 미생성, 환경변수 기반 연동 경계, 비공개 영상 토큰 경계·설계, 단일 VM/DB 배포 구성.
- 아직 미구현: 실제 저장량 계량·신규 업로드 용량 예약·일일 비용 집계·예산 알림·요청 한도 차단.
- 운영 전: 60%/80%/90% 비용 알림, 스토리지 용량 상한, 비정상 요청 방어, 월별 신규 업로드·인코딩 사용량 관리, 업체별 실제 하드 제한 지원 여부 확인.
- 업체 청구는 지연 집계될 수 있어 앱의 제한만으로 **정확한 10만 원 하드 캡을 보장할 수 없다**. 제한 도달 시 어떤 기능을 보류할지 고객과 합의한다. 기본적으로 신규 업로드·대량 변환을 먼저 보류하고 기존 수강을 임의 차단하지 않는다.
- 문자·알림톡·메일·PG 수수료·도메인·선택 유지보수는 계약상 외부 운영 항목이며 위 서버/영상 예산과 별도 집계. 고객이 이 비용도 10만 원에 포함하려면 재산정 필요.
