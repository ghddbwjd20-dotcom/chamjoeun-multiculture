# 남은 개발·오픈 작업

확인일: 2026-11-02. 현재 운영 환경변수 이름과 외부 PostgreSQL 데이터를 직접 대조했습니다.

## 완료된 기반

외부 PostgreSQL 연결, 관리자 계정·로그인, 홈페이지/기관소개/연혁, 기관소식·문의 관리, 업무협약 공개 20건과 이미지 30장, 관리자 원본 보관·열람은 반영했습니다. 과정·수강·진도·결제·OAuth·PDF의 기반 코드와 화면도 있습니다. 기반 코드 존재와 실제 서비스 연동 완료는 구분합니다.

## 우선 진행할 작업

1. **인증메일 연결**: Resend 발송 도메인·MAIL_FROM·키 설정과 가입 인증/재발송/비밀번호 복구 실메일 검증. 현재 운영 환경에 메일 설정이 없어 일반 회원가입을 차단하는 상태입니다.
2. **강의 영상 실연동**: R2/S3 버킷·키·CORS, 재생 Worker·서명 키, FFmpeg 변환 작업자 실행 서버를 연결합니다. 실제 MP4 업로드 → 변환 → 수강 권한 → 모바일·장시간 재생·진도 저장까지 검수해야 합니다.
3. **실제 교육 콘텐츠**: 초기 5과정·총 30차시의 원고·강사·기간·가격·영상·수료 기준을 등록합니다. 현재 외부 DB의 공개 과정 0건, 재생 준비 완료 차시 0건입니다.
4. **결제·소셜로그인 실연동**: 토스 키·승인·웹훅·전체취소·수강권 검증, 네이버/카카오/구글 앱 키·콜백과 계정 연결 검증이 필요합니다. 운영 설정은 아직 없습니다.
5. **발급·알림 운영 기능**: 기관 승인 수료증/자격증 양식 확정 및 실제 PDF 발급 검수. 문자·알림톡·Web Push·뉴스레터의 발송 작업자, 실패/재시도·수신거부·이력 화면은 개발이 남았습니다. 문의 자동 이메일 답변도 별도 연동이 필요합니다.
6. **정책·오픈 검수**: 재수강·기간 연장·환불·수료 정책과 개인정보 보유/파기·약관 확정. 외부 DB 일일 백업·복구, 오류·비용 모니터링, 실제 영상 50명 동시 시청·모바일·접근성 검수를 진행합니다.

추가 확인: '(안)' 표기가 있는 협약 자료 1건은 체결 확정 여부 확인 후 공개 처리합니다.

## 이번 메인 영상 보완

도서관 사진 대신 현재 hero-navy.mp4의 실제 첫 프레임을 hero-video-poster.jpg로 추출했습니다. 동일 장면을 로딩 배경과 video poster로 사용하고, 첫 영상 프레임 준비 후 300ms 전환합니다. 영상 실패 시 같은 정지 화면을 유지하며 움직임 최소화 환경에서는 전환 효과를 끕니다.

검증: 타입 검사와 Vercel Webpack 빌드 통과. 별도 테스트 브라우저에서 영상 지연 로딩·첫 프레임 준비 후 전환·모바일 영상 실패 시 정지 화면 유지를 확인했습니다. 캐시 영상이 React 초기화 전에 준비된 경우도 상태를 동기화합니다. 교체한 정지 이미지의 배포 바이트 일치도 확인했습니다.
